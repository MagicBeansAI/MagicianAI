# Magician Feature Map

This is the short operator-facing map of what Magician can do, what each feature
is useful for, and the commands or routes that are most often relevant. Detailed
design and implementation notes live in the linked component docs.

For the smaller product-level view, start with the
[Magican Ecosystem Map](../ecosystem/README.md).

## Common Operator Flows

```bash
# Fresh local setup
make setup-all
make -C skillshub setup-all

# Run the full local stack
make run-all
make stop-all

# Run only backend or only UI
make run-supervisor
make stop-supervisor
make run-ui-dev
make stop-ui-dev

# Run all Rust, Unified UI Svelte/TypeScript, and iOS compile checks
make check-all

# Run only the Unified UI Svelte/TypeScript checker
make check-ui
git diff --check

# Inspect logs
make tail-service-log SERVICE=stack
make tail-service-log SERVICE=magician
make tail-magician-v2-log

# Channel Assist fixtures/evals
magician channel-assist export-fixtures --limit 200
magician channel-assist classify-eval --fixtures <fixtures.jsonl>
```
