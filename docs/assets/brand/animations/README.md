# The star's moods (Lottie)

Ten looping animations of the Magican star, drawn after the brand board (`../mascot-primary.png`, `../mascot-poses.png`):
a puffy soft-3D star, thick round glasses with ^^ eyes and no mouth, black stick arms with round mitten hands, stick legs with
rounded shoes, and its companion: a glossy ball with three dashes, both the same colour.

| Mood | File | Loop | What it does |
|---|---|---|---|
| Celebrate | `celebrate.json` | 2 s | Crouches, jumps with both arms up and shaking, confetti and sparkles, lands with a squash |
| Thinking | `thinking.json` | 3 s | A hand at the chin, tapping; a slow sway; eyes up; thought bubbles rise to the ball |
| Asking | `asking.json` | 2 s | A hand up, a small wave, a curious tilt; a question mark is drawn above the ball (its dot) |
| Sleeping | `sleeping.json` | 4 s | Eyes closed, arms hanging, slow breathing, a lean; Zs float away; the ball rests |
| Hi | `hi.json` | 2 s | A big wave |
| Got it | `got-it.json` | 2 s | A nod and a thumbs up; a green tick drawn by the ball |
| Working | `working.json` | 1.6 s | Typing at a laptop (a small star glows on its lid); the dashes run like a loader |
| On it | `on-it.json` | 1.1 s | A brisk walk, arms and legs swinging, speed lines |
| Waiting | `waiting.json` | 3 s | Hands on hips, a foot tap, glancing left and right; the dashes tick like a loader |
| Side quest | `side-quest.json` | 3.2 s | A bouncing walk through spinning gold coins, with collection sparkles and floating +1 rewards |

Each has a dark-background version, `<mood>-dark.json`: the ball, dashes, Zs and question mark turn gold (the brand rule:
on dark backgrounds they glow gold). 512×512, 30 fps, 10–40 KB each.

`preview.html` plays them all (open it in a browser; a button switches light and dark).

## Using them

- Web: `lottie-web` (already in unified-ui): `lottie.loadAnimation({ container, renderer: "svg", loop: true, autoplay: true, path: "/brand/animations/thinking.json" })`.
  Pick `-dark` with `prefers-color-scheme: dark`.
- iOS: `lottie-ios` (`LottieAnimationView(name: "thinking")`, the JSON in the app bundle).
- Android: `lottie-android` (`LottieAnimationView`, the JSON in `res/raw/` or `assets/`).

The root landing uses runtime copies in `static/brand/animations/` through
`BrandMascot.svelte`.
It continuously loops the greeting or current example mood, pauses off-screen,
and selects `-dark`
when the landing switches to Night. `/brand/mascot-hi-light.svg` and
`mascot-hi-dark.svg` are static exports of frame 15 from the matching `hi` files;
regenerate those poses alongside a changed drawing. Reduced-motion visits use
those SVGs without loading the player or animation JSON.
Work uses `working`, Play uses `on-it`, and Side quests uses `side-quest`.
Pausing the example carousel leaves the current mascot loop playing.

## Making more

They are generated by `tools/build-mascot-lottie.py` in the launch-video repo (magican_launch_video; copy the output here and to `ui/unified-ui/static/brand/animations/`): poses, timings and
colours are code. Add a mood there and run it; it writes both the light and the dark file.

The coin-collecting Side quest extends the checked-in `on-it` rig. Regenerate it
with `python3 scripts/build_landing_quest_mascot.py` from the repo root. That
command writes both theme variants to the source and runtime directories and
updates the animation preview. It uses vector shapes without image or font
dependencies.
