🧪 Code Editor Test

This page tests typing into code editors that use virtual DOM (Monaco, CodeMirror).

Goal: Verify that text is entered correctly and the 6-phase verification finds it.

Test 1: Monaco Editor

Monaco Editor (used by VS Code) renders text in .view-line elements with virtual scrolling.

Loading Monaco Editor...
Test Steps:
  1. Wait for Monaco Editor to load (should show syntax highlighting)
  2. Click inside the editor area
  3. Use typeAtCoordinates to type: console.log('hello world');
  4. Check console logs for verification result
Expected: Text appears in editor. Logs show: verified: true, where: "mainPage" (found via Phase 2 editor selectors)
Failure Mode: Text doesn't appear, or logs show verified: false
If this fails, verification is not finding text in .view-line elements.
