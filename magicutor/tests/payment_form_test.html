🧪 Payment Form Test

This page tests typing into iframe inputs, simulating payment forms like Stripe.

Goal: Verify that text is entered ONCE (no double-typing) and verification works correctly.

Test 1: Same-Origin Iframe Input

This iframe is same-origin (uses srcdoc), so verification should work via direct DOM access.

Test Steps:
  1. Attach debugger to this tab via Magicutor
  2. Click inside the card number field in the iframe
  3. Use typeAtCoordinates to type: 4242424242424242
  4. Check console logs for verification result
Expected: Text "4242424242424242" appears ONCE. Logs show: verified: true, where: "mainPage" or where: "iframe:..."
Failure Mode: Text appears twice (double-typing bug) or logs show verified: false

Test 2: Multiple Input Fields

Tests verification across multiple inputs in the same iframe.

Test Steps:
  1. Click on Card number field → type 4111111111111111
  2. Click on MM/YY field → type 12/25
  3. Click on CVC field → type 123
  4. Verify each field shows correct text (no doubles)
