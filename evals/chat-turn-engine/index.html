Chat turn engine

Harness lane for the chat-mouth seam. Visible on /evals via Makefile annotation test-chat-turn-engine-eval (kind=harness, report=evals/chat-turn-engine).

What this lane pins:

  • Default / unknown engine names fail closed to Magician's own mouth.
  • Roster names select a harness; ChatScoped grants keep the conversation surface.
  • Every launchable roster name is a chat mouth. Native-tool posture is per engine (stripped or sandboxed).
  • ChatScoped grants resolve at the process-local MCP door.
  • Grant revoke cancels a child of the chat-turn token, not the conversation.
  • Warm resume sends only the new user text.
  • Gated plane actions refuse (chat HITL is the next user message).
  • A conversation grant's tools/call crosses the plane door.
