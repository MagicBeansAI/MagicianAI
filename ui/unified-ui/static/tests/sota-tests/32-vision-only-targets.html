3. Draw a continuous stroke through numbered waypoints

32-stroke-waypoints
Goal: Press and drag a single continuous stroke that passes through every numbered waypoint in ascending order (1 → 2 → 3 → 4). Lifting the pointer before all waypoints are reached cancels the attempt and clears the canvas. The next required waypoint is the one outlined in yellow.

Stroke Canvas

Numbered waypoints — positions and order randomized on load.

Stroke Canvas
Coordinates are not exposed via DOM or window. The numbers shown on the canvas indicate the required order.
Verification:
  • A continuous pointer stroke must begin on the canvas.
  • Each numbered waypoint must be touched in ascending order during the same stroke.
