Cross-Origin Iframe Typing

Test the agent's ability to type into real cross-origin iframes and verify text using CDP session attachment.

Note: These are REAL cross-origin iframes. The extension needs to:
  • Detect the iframe via Target.setAutoAttach
  • Get or create a CDP session for the iframe
  • Use Runtime.evaluate with the session to verify text inside

Test 1: Type in CodeSandbox

15-codesandbox-typing
Goal: Wait for CodeSandbox to load (5-10 seconds), click inside the code editor area, and type: const test = 'verification works!';
Verification:
  • Text should appear in the CodeSandbox editor
  • Verification should use iframe CDP session
  • Console should show: verified: true, where: "iframe:..."
Cross-Origin: codesandbox.io

Test 2: Type in StackBlitz

15-stackblitz-typing
Goal: Wait for StackBlitz to fully load (10-15 seconds), click inside the index.js editor, and type: console.log('stackblitz test');
Verification:
  • Text should appear in the StackBlitz editor
  • WebContainer-based editor should be handled correctly
Cross-Origin: stackblitz.com
