Phase 0.5: Parent-Frame Occlusion Detection

Test the agent's ability to detect when elements are covered by overlays, modals, or other parent-frame elements.

Test Controls:

Test 1: Detect Occluded Elements

02-detect-occlusion
Goal: Click "Show Blocking Modal" above, then attempt to click the "Submit Form" button inside the iframe below. The agent should detect that the button is blocked by the modal.
Verification:
  • Agent detects that the iframe content is occluded by the modal
  • Agent does NOT attempt to click the hidden button immediately
  • Agent reports that the element is not clickable/visible OR offers to dismiss modal first

Test 2: Dismiss Modal and Click

02-dismiss-and-click
Goal: With the modal shown, close the modal by clicking the "Close" button on it, then click the "Submit Form" button inside the iframe.
Verification:
  • Agent clicks the "Close" button on the modal to dismiss it
  • Modal disappears from the page
  • Agent then successfully clicks the Submit button in the iframe

Test 3: Partial Occlusion Detection

02-partial-occlusion
Goal: Click "Show Floating Banner" above to show a floating element that partially covers the iframe. Then click the "Right Button" inside the iframe below.
Verification:
  • Left Button should be clickable (not occluded)
  • Right Button may be partially occluded by the banner
  • Agent handles partial occlusion appropriately (dismisses banner or reports issue)
