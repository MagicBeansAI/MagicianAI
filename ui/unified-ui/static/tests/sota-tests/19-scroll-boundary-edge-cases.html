Test 2: Shadow DOM Scroll Container SHADOW DOM

boundary-02
Goal: Click on the item labeled "Shadow Target Item" inside the custom element's scrollable shadow DOM list.
Verification:
  • Shadow DOM list was scrolled to reveal the target
  • Target item was clicked and highlighted

Scenario: A custom element (<scroll-list>) with a scrollable list inside its shadow DOM. The scroll container detection must cross the shadow boundary via getRootNode().host.

Test 3: overflow:clip Boundary CSS3 CLIP

boundary-03
Goal: Click on "Clip Target Item" inside the list that is wrapped in an overflow: clip container. The inner list scrolls, but the outer container uses CSS overflow: clip as the clipping boundary.
Verification:
  • Inner list was scrolled within the clip boundary
  • Target item was clicked and highlighted

Scenario: An outer overflow: clip container wraps a scrollable inner list. The getVisibleRectAfterClipping() function must recognize overflow: clip as a clipping boundary, and getScrollContainerClipInfo() must report clipping against it.

Test 4: Same-Origin Iframe Scroll Container IFRAME

boundary-04
Goal: Click on "Iframe Target Item" inside a scrollable list that lives within a same-origin iframe. The scroll container detection must cross the iframe boundary.
Verification:
  • List inside iframe was scrolled to reveal the target
  • Target item was clicked and highlighted

Scenario: A same-origin iframe contains a scrollable list. The getScrollContainerInfo() function must use ownerDocument.defaultView.frameElement to cross the iframe boundary and continue searching for scroll ancestors in the parent document.

Test 5: Deeply Nested Scroll Containers NESTING

boundary-05
Goal: Click on "Deep Nested Target" inside an inner scrollable list, which itself is inside an outer scrollable panel. Both the inner and outer containers require scrolling.
Verification:
  • Outer panel was scrolled to reveal the inner list
  • Inner list was scrolled to reveal the target
  • Target item was clicked and highlighted

Scenario: Outer scrollable panel contains multiple sections. One section has an inner scrollable list. The target item is deep in the inner list. getScrollContainerInfo() should report the nearest scrollable ancestor (the inner list), enabling the agent to scroll it directly.
