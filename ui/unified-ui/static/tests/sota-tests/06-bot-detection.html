Phase 4: Bot Detection

Test the agent's ability to detect and avoid honeypot fields, recognize CAPTCHAs, and identify anti-bot measures.

Test 1: Detect Honeypot Fields

06-honeypot-fields
Goal: Fill out this contact form with name "John Doe", email "john@example.com", and message "Hello, this is a test message." Then submit the form. Do NOT fill any hidden fields.
Verification:
  • Only visible fields (name, email, message) should be filled
  • Hidden honeypot fields (website, fax, address_confirm) should remain empty
  • Form should submit successfully with "No honeypot fields were filled" message
Honeypot Detection Signals:
  • visibility: hidden + form field
  • opacity: 0 + form field
  • display: none + input
  • tabindex="-1" (skip in tab order)
  • Fields named: website, url, fax, address_confirm

Test 2: CAPTCHA Recognition

06-captcha-detection
Goal: Attempt to log in with username "testuser" and password "password123". Note: A CAPTCHA is present and must be acknowledged.
Verification:
  • Agent should detect and report the CAPTCHA presence
  • Agent should indicate that human intervention may be required
  • Username and password fields should be filled correctly
I'm not a robot 🤖 reCAPTCHA

Test 3: Rate Limit Detection

06-rate-limiting
Goal: Click the "Trigger Action" button 5 times quickly. After 3 clicks, a rate limit warning should appear. The agent should detect this and stop or report the rate limiting.
Verification:
  • Rate limit banner should appear after 3 clicks
  • Agent should detect "slow down" / "too many requests" pattern
  • Agent should stop clicking or report the rate limiting
