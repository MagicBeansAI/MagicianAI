# Office Excel

Tool name: `office-excel`

This is the Excel-specific surface over the shared OfficeCLI binary. Use it
when the final artifact must be an editable local `.xlsx` workbook: trackers,
models, pivots, dashboards, formulas, charts, tables, validation, conditional
formatting, or template-filled reports.

Use `sheets` when the user wants a collaborative Google Sheet or provides a
Google Sheets URL. Use `csvkit`, DuckDB, or Marimo for analysis that does not
need an Excel deliverable. Use `office-word` for `.docx` and
`office-powerpoint` for `.pptx`.

## Required workflow

1. Inspect an existing workbook with `view` mode `outline` or `text`, then use
   targeted `get` calls for sheet names, ranges, formulas, tables, and charts.
2. Preserve the input. Create a new output file unless the user explicitly
   requested an in-place edit.
3. Call `load_guidance` once per artifact: `excel` for normal workbooks,
   `financial-model` for projections/scenarios, or `data-dashboard` for KPI and
   analytics dashboards.
   Treat that guide as domain and quality guidance only. This skill's exposed
   action catalog and no-resident policy take precedence over guide examples
   that mention unavailable commands such as `open`, `save`, or `raw-set`.
4. Use `help` before guessing an element, formula, chart, pivot, or property.
5. Prefer `batch` for data loads and multi-cell formatting so the workbook is
   opened and saved once.
6. Verify formulas and representative computed values with the smallest useful
   `get` range. Check totals, units, date formats, and error cells explicitly.
7. Before delivery, run `validate`, `view` mode `issues`, and a rendered
   `html` or `screenshot` check for every user-facing sheet.

## Command conventions

- Paths use sheet-qualified forms such as `/Sheet1/A1` and selectors such as
  `Sheet1!row[Revenue>5000]`.
- `extra_args` is an argv array, not a shell string. For cell properties use
  tokens such as `["--prop", "value=42", "--prop", "bold=true"]`.
- Formulas must start with `=` and should be written as one literal argv value.
- The tool adds `--json` automatically to operational commands.
- Auto-update and auto-resident processes are disabled by the runtime. Use `batch`
  rather than opening a persistent OfficeCLI resident.

## Safety and quality

- Do not overwrite the only copy of a user workbook.
- Inspect the exact sheet/range immediately before `remove`, broad replacement,
  or structural movement.
- Preserve existing formulas, named ranges, validations, print settings,
  hidden sheets, and chart sources unless the request changes them.
- Do not ship hard-coded values where a formula is expected.
- A workbook is not complete merely because it opens: schema validation,
  formula/value spot checks, issue inspection, and visual QA are required.
